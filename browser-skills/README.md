
- Includes every `.md` file exposed by each catalog entry’s file API. The 12 entries whose file API returns 404 already live in this repository; their Markdown was downloaded from the public GitHub source URL in the catalog at commit `6811ca31163332d9d60309cff48e77f09de37a17`.
- No scripts, binaries, screenshots, archives, or other non-Markdown assets are copied. Script-backed skills need their original full distribution: use `browse skills add <catalog-slug>` or the upstream source linked below. These snapshots provide visibility and do not replace those distributions.
- Skill bodies and supporting Markdown are preserved. Trailing whitespace is removed. The `name` frontmatter is namespaced with the hostname and catalog task (shortened with a stable hash when needed) so different sites and existing skills do not collide. The table maps every exported name to its original catalog entry.
- Upstream status and metadata are preserved, including draft entries. Exporting an entry does not imply it was executed or newly verified.
- The marketplace manifest explicitly lists these paths. Without it, the Skills CLI finds the existing `skills/` collection first and skips this sibling folder in its default scan.

The public repository contains the CLI, not the directory web application.
